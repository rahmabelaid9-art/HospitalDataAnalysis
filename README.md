# HospitalDataAnalysis

## Project Description
This project analyzes hospital patient data using Python.

## Objectives
- Load patient data from a CSV file.
- Calculate descriptive statistics.
- Count patients by sex and diagnosis.
- Visualize the relationship between age and cholesterol.

## Libraries
- pandas
- numpy
- matplotlib
- jupyter

## Project Structure
- `data/`: Contains the patient dataset (`patients.csv`).
- `notebooks/`: Contains the analysis notebook (`patients_analysis.ipynb`).
- `scripts/`: Contains optional Python scripts.
- `requirements.txt`: Lists the required Python packages.
- `.gitignore`: Specifies files and folders ignored by Git.

## How to Run
1. Create and activate a Python virtual environment.
2. Install the required libraries using `python -m pip install -r requirements.txt`.
3. Start Jupyter Notebook using `python -m jupyter notebook`.
4. Open `notebooks/patients_analysis.ipynb`.
5. Run the notebook cells in order.

## Dataset
The dataset contains fictional patient data for educational purposes.
